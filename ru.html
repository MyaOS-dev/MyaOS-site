MyaOS

Операционная система, которая запускает программы из разных ОС прямо из коробки.

Написана с нуля: свой UEFI-загрузчик, своё ядро, встроенная поддержка форматов .sh, .exe, .app, .AppImage, .msi и других.

О проекте

MyaOS — операционная система, разрабатываемая с нуля: собственный UEFI-загрузчик, собственное ядро и встроенная поддержка форматов исполняемых файлов из других операционных систем. Пользователю не нужно думать, для какой системы собрана программа, — MyaOS просто её запускает.

Цель

Операционная система с поддержкой программ из разных ОС из коробки (Out-of-Box), без установки дополнительного ПО и без разбирательств с типами исполняемых файлов.

Форматы исполняемых файлов

ELFВ работе

Executable and Linkable Format — стандартный формат исполняемых файлов и общих объектов в Unix/Linux.

Что требуется сделать?
  • Изучить архитектуру ELF
  • Написать парсер
  • Написать executor

PE/COFFВ работе

Portable Executable / Common Object File Format — формат исполняемых файлов Windows (.exe, .dll, .sys).

Что требуется сделать?
  • Изучить архитектуру PE/COFF
  • Написать парсер
  • Написать executor

Mach-OВ работе

Mach Object — формат исполняемых файлов macOS и iOS.

Что требуется сделать?
  • Изучить архитектуру Mach-O
  • Написать парсер
  • Написать executor

MZВ работе

Исторический формат DOS-исполняемых файлов. Изучается для работы аппаратного гипервизора с DOS-системой.

Что требуется сделать?
  • Изучить архитектуру MZ

Гипервизор

  • Изучить архитектуру аппаратных гипервизоров
  • Реализовать аппаратный гипервизор с DOS-системой

Актуальность

На сегодняшний день нет операционных систем с поддержкой программ из других ОС из коробки. Это неудобно для обычных пользователей, которые не разбираются в типах исполняемых файлов и не хотят вникать в особенности каждой платформы.
