About

MyaOS is an operating system built from scratch: its own UEFI bootloader, its own kernel and built-in support for executable formats from other operating systems. The user doesn't need to think about which system a program was built for — MyaOS just runs it.

Goal

An operating system with out-of-the-box (Out-of-Box) support for programs from different OSes — without installing extra software and without dealing with executable file types.

Development roadmap

Boot and kernel

  • Study the UEFI architecture
  • Write a UEFI bootloader
  • Study how existing kernels work
  • Write our own kernel

Scheduler

  • Round Robin multitasking

Executable formats

ELFIn progress

Executable and Linkable Format — the standard format for executables and shared objects on Unix/Linux.

What needs to be done?
  • Study the ELF architecture
  • Write a parser
  • Write an executor

PE/COFFIn progress

Portable Executable / Common Object File Format — the executable format for Windows (.exe, .dll, .sys).

What needs to be done?
  • Study the PE/COFF architecture
  • Write a parser
  • Write an executor

Mach-OIn progress

Mach Object — the executable format for macOS and iOS.

What needs to be done?
  • Study the Mach-O architecture
  • Write a parser
  • Write an executor

MZIn progress

The legacy DOS executable format. Studied for the hardware hypervisor with a DOS system.

What needs to be done?
  • Study the MZ architecture

Hypervisor

  • Study hardware hypervisor architectures
  • Implement a hardware hypervisor with a DOS system

Why it matters

Today there is no operating system with built-in support for programs from other OSes. This is inconvenient for ordinary users who don't understand executable file formats and don't want to deal with platform specifics.
